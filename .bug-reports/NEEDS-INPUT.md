Findings from `.bug-reports/2026-09-17.md`, fixed locally this run and then discarded
(`git reset --hard`) because they could not be verified with a build:
- **The mod's 4 custom network packet handlers trust a client-supplied player index instead of the
  real sender, letting any client forge another player's Chakra/Stamina/Transformation/
  MoonLordBlessing state** (high bug): `Common/Players/TransformationPlayer.cs:392-411`,
  `Common/Players/MoonLordBlessingPlayer.cs:56-71`, `Common/Players/ChakraPlayer.cs:177-181`,
  `Common/Players/StaminaPlayer.cs:189-193` - fix makes `TransformationPlayer.HandlePacket` and
  `MoonLordBlessingPlayer.HandlePacket` use the tModLoader-supplied `whoAmI` (the real sender) as
  the write target when running as the server, instead of the attacker-controlled `playerIndex`
  byte in the packet payload (still trusts the payload's index on the client, where it's a
  server-validated relay). `ChakraPlayer.HandleCorrectionPacket` and
  `StaminaPlayer.HandleCorrectionPacket` now drop the packet unless `Main.netMode ==
  NetmodeID.MultiplayerClient`, since a correction packet is only ever legitimately sent
  server -> client and a forged copy sent by a client straight to the server must not be applied
  to the server's authoritative state. Wire format unchanged in all four cases.
- **extract_tmod.py's rawimg decoder crashes with an unhelpful raw exception (instead of a clear
  error) on a truncated or corrupt `.rawimg` entry** (medium bug): `tools/extract_tmod.py:92-97`
  (`rawimg_to_pil`) - fix validates `width`/`height` are positive and that enough pixel-data bytes
  are actually present before slicing, raising a clear `ValueError` naming the shortfall instead of
  letting `Image.frombytes` fail with a generic traceback later.
- **extract_tmod.py's `extract` command raises a bare IndexError instead of the usage message when
  called with too few arguments** (improvement): `tools/extract_tmod.py:100-113` (`main`) - fix
  adds a `len(sys.argv) < 5` guard on the `extract` branch, mirroring the existing guard pattern
  used elsewhere in the file.
