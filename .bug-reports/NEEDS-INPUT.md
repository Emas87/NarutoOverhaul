## Design decisions
### Hiraishin seals planted by a non-host client never register with the server's authoritative mark registry
- Report: .bug-reports/2026-09-19.md
- Location: Content/Projectiles/MinatoKunaiProjectile.cs:102-124, Common/Systems/HiraishinMarkerSystem.cs:93-118
- The decision: how to make seal placement authoritative when thrown by a non-host client, since `HiraishinMarkerSystem.SyncToClients()` only fires server-side and the raw `SendTileSquare` packet a non-host client sends never invokes `PlaceInWorld`/`AddMark` on the server.
- Options: A) Add a dedicated `AddMark` network packet the owning client sends to the server (consistent with how Chakra/Stamina/Transformation state already sync). B) Have the owning client only place the tile locally for prediction and make the *server* perform the authoritative `WorldGen.PlaceObject`/`AddMark` once it independently detects the projectile's tile-collide event, requiring the placement logic to run server-side rather than client-side.
