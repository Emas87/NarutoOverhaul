## Design decisions
### Does EncourageDespawn actually work for TailedBeastBoss the way it does for its sibling bosses?
- Report: .bug-reports/2026-09-20.md
- Location: Content/NPCs/Bosses/TailedBeastBoss.cs:198-211
- The decision: confirm in a real multiplayer test whether `NPC.EncourageDespawn(10)` is defeated by
  the dead player's screen still showing the boss (as the existing code comment claims), before
  deciding how to fix the "boss vanishes the instant its target dies" bug.
- Options: A) the sibling-boss premise holds - swap in the same
  `NPC.velocity.Y -= 0.2f; NPC.EncourageDespawn(10); return;` pattern used by `HakuBoss`/
  `KakuzuBoss`/`MadaraBoss`/`OrochimaruBoss`. B) the existing comment's premise is correct and
  `EncourageDespawn` really doesn't work here - add an explicit no-target grace timer gated behind
  `Main.netMode != NetmodeID.MultiplayerClient` so only the server/singleplayer authoritatively
  decides to deactivate, instead of every client's shadow AI copy deactivating independently.
