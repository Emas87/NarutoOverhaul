### Should smoke_test_server.sh's exception-text WARNING also fail the script?
- Report: .bug-reports/2026-09-12.md
- Location: tools/smoke_test_server.sh:33-37
- The decision: whether a log containing exception-like text (currently just prints `WARNING:`) should also cause a nonzero exit, or stay deliberately non-fatal because it can include false positives (e.g. an NPC literally named "Exception", or benign caught-and-logged framework noise).
- Options: A) Only the `FAIL:` (no clean start) branch exits nonzero; `WARNING:` stays informational for a human to skim. C) `WARNING:` exits nonzero only when paired with an exclusion list for known-benign strings - more complex, probably not worth it for a dev tool.
